# ระบบสารสนเทศเพื่อการจัดการหอพัก — หอพักชื่นเย็นแมนชั่น

เว็บแอปสำหรับจัดการห้องพัก ผู้เช่า มิเตอร์น้ำ-ไฟฟ้า การชำระเงิน แจ้งซ่อม และรายงาน
สร้างด้วย **Next.js** (frontend) + **Supabase** (ฐานข้อมูลจริง PostgreSQL) และ deploy ขึ้น **Vercel** ได้ URL จริงใช้งานได้จากทุกที่

---

## ภาพรวมขั้นตอนทั้งหมด

1. สร้างฐานข้อมูลบน Supabase (ฟรี)
2. เชื่อมโปรเจกต์นี้กับ Supabase
3. ทดสอบรันบนเครื่องตัวเอง (ไม่บังคับ แต่แนะนำ)
4. อัปโหลดโค้ดขึ้น GitHub
5. Deploy ขึ้น Vercel (ฟรี) → ได้ URL จริง

ใช้เวลารวมประมาณ 20–30 นาที ไม่ต้องเขียนโค้ดเพิ่ม

---

## ขั้นตอนที่ 1: สร้างฐานข้อมูลบน Supabase

1. ไปที่ https://supabase.com แล้วสมัครสมาชิก (ใช้ GitHub login ได้)
2. กด **New Project**
   - ตั้งชื่อโปรเจกต์ เช่น `cheun-yen-dorm`
   - ตั้งรหัสผ่านฐานข้อมูล (เก็บไว้ให้ดี)
   - เลือก Region ใกล้ประเทศไทย เช่น Singapore
   - กด Create new project แล้วรอประมาณ 1-2 นาที
3. เมื่อโปรเจกต์พร้อมแล้ว ไปที่เมนูซ้าย **SQL Editor**
4. เปิดไฟล์ `supabase/schema.sql` ในโปรเจกต์นี้ คัดลอกทั้งหมด แล้ววางในช่อง SQL Editor
5. กด **Run** — ระบบจะสร้างตารางทั้งหมด (ห้องพัก ผู้เช่า มิเตอร์ การชำระเงิน แจ้งซ่อม การตั้งค่า) พร้อมข้อมูลตัวอย่าง 8 ห้องให้อัตโนมัติ
6. ไปที่เมนู **Project Settings → API** แล้วคัดลอกค่า 2 อย่างเก็บไว้:
   - **Project URL** (เช่น `https://xxxxx.supabase.co`)
   - **anon public key** (กุญแจสาธารณะ ยาวๆ)

---

## ขั้นตอนที่ 2: ตั้งค่าโปรเจกต์

1. เปิดโฟลเดอร์โปรเจกต์นี้ คัดลอกไฟล์ `.env.local.example` แล้วเปลี่ยนชื่อเป็น `.env.local`
2. ใส่ค่าที่คัดลอกมาจาก Supabase:

```
NEXT_PUBLIC_SUPABASE_URL=https://xxxxx.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=ใส่ anon public key ที่นี่
```

---

## ขั้นตอนที่ 3: ทดสอบรันบนเครื่องตัวเอง (แนะนำก่อน deploy จริง)

ต้องติดตั้ง [Node.js](https://nodejs.org) เวอร์ชัน 18 ขึ้นไปก่อน จากนั้นเปิด terminal ในโฟลเดอร์โปรเจกต์:

```bash
npm install
npm run dev
```

เปิดเบราว์เซอร์ไปที่ `http://localhost:3000` ควรเห็นหน้าแอปพร้อมข้อมูลห้องพัก 8 ห้อง
ถ้าเห็นข้อความ "เชื่อมต่อฐานข้อมูลไม่สำเร็จ" ให้ตรวจสอบค่าใน `.env.local` อีกครั้ง

---

## ขั้นตอนที่ 4: อัปโหลดโค้ดขึ้น GitHub

1. สร้าง repository ใหม่บน https://github.com (เช่นชื่อ `cheun-yen-dorm`)
2. ในโฟลเดอร์โปรเจกต์:

```bash
git init
git add .
git commit -m "ระบบจัดการหอพักชื่นเย็นแมนชั่น"
git branch -M main
git remote add origin https://github.com/ชื่อผู้ใช้/cheun-yen-dorm.git
git push -u origin main
```

(ไฟล์ `.env.local` จะไม่ถูกอัปโหลดเพราะอยู่ใน `.gitignore` แล้ว — ปลอดภัย)

---

## ขั้นตอนที่ 5: Deploy ขึ้น Vercel

1. ไปที่ https://vercel.com แล้วสมัคร/ล็อกอินด้วย GitHub
2. กด **Add New → Project**
3. เลือก repository `cheun-yen-dorm` ที่เพิ่ง push ไป
4. ในหน้า Configure Project ให้เปิดส่วน **Environment Variables** แล้วเพิ่ม:
   - `NEXT_PUBLIC_SUPABASE_URL` = ค่า Project URL จาก Supabase
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY` = ค่า anon public key จาก Supabase
5. กด **Deploy** แล้วรอประมาณ 1-2 นาที
6. เสร็จแล้ว! จะได้ URL จริง เช่น `https://cheun-yen-dorm.vercel.app` ใช้งานได้จากมือถือ/คอมพิวเตอร์เครื่องไหนก็ได้

---

## โครงสร้างโปรเจกต์

```
app/
  layout.js        โครงหน้าเว็บหลัก + ฟอนต์
  page.js          หน้าแอปทั้งหมด (ภาพรวม/ห้องพัก/ผู้เช่า/มิเตอร์/การชำระเงิน/แจ้งซ่อม/รายงาน)
  globals.css      สไตล์พื้นฐาน + Tailwind
lib/
  supabaseClient.js  การเชื่อมต่อ Supabase
  api.js             ฟังก์ชันดึง/บันทึกข้อมูลแต่ละตาราง
supabase/
  schema.sql         คำสั่งสร้างตารางฐานข้อมูลทั้งหมด
```

## ขอบเขตของระบบ (ตรงตามแบบเสนอหัวข้อโครงการ)

- จัดการข้อมูลห้องพัก / ผู้เช่า / มิเตอร์น้ำ-ไฟ / การชำระเงิน / แจ้งซ่อม
- คำนวณค่าน้ำ-ค่าไฟจากเลขมิเตอร์อัตโนมัติ, ปรับสถานะห้องว่าง/ไม่ว่างอัตโนมัติ
- รายงานระดับปฏิบัติการ (TPS): ห้องว่าง-ไม่ว่าง, ทะเบียนผู้เช่า, รายการค้างชำระ, ใบแจ้งหนี้
- รายงานสรุปผู้บริหาร (MIS): อัตราการเข้าพัก, รายรับรวมรายเดือน, ยอดค้างชำระ
- **ยังไม่รวม** (ตามขอบเขตเดิม): ระบบชำระเงินออนไลน์, ระบบแจ้งซ่อมผ่านแอปมือถือ, ระบบล็อกอิน/สิทธิ์ผู้ใช้

## หมายเหตุด้านความปลอดภัย

โปรเจกต์นี้เปิดให้ทุกคนที่มีลิงก์อ่าน-เขียนข้อมูลได้ (เหมาะสำหรับงานสาธิต/ส่งอาจารย์)
หากต้องการนำไปใช้กับหอพักจริง ควรเพิ่ม **Supabase Auth** สำหรับผู้ดูแล แล้วแก้ไข RLS policy ในไฟล์ `supabase/schema.sql`
ให้ตรวจสอบผู้ใช้ที่ล็อกอินแล้วเท่านั้นก่อนอนุญาตให้อ่าน/เขียนข้อมูล
